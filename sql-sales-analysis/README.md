# SQL Sales Analysis

## Objetivo
Analizar datos de ventas para identificar patrones, KPIs y oportunidades de mejora en la toma de decisiones de negocio.

## Dataset
Datos simulados de ventas que incluyen información de clientes, productos, fechas y montos de compra.

## Herramientas
- SQL (MySQL / SQL Server)

## KPIs analizados
- Total de ventas
- Ventas por producto
- Ventas por mes
- Clientes más frecuentes

## KPIs de negocio
- Ticket promedio
- Frecuencia de compra
- Ventas por categoría

## Consultas realizadas
- JOIN entre tablas para integración de datos
- GROUP BY para agregaciones
- Filtrado de datos relevantes
- Ordenamiento por métricas clave

## Resultados
- Identificación de productos más rentables
- Detección de tendencias de ventas mensuales
- Análisis del comportamiento de clientes

## Enfoque de análisis
Aplicación de consultas SQL para transformar datos en información útil, permitiendo identificar oportunidades de mejora en ventas y eficiencia operativa.
