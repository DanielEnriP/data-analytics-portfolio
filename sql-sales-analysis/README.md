# SQL Sales Analysis

## Objetivo
Analizar datos de ventas para identificar patrones, KPIs y oportunidades de mejora.

## Herramientas
- SQL (MySQL / SQL Server)

## KPIs analizados
- Total de ventas
- Ventas por producto
- Ventas por mes
- Clientes más frecuentes

## Consultas realizadas
- JOIN entre tablas
- GROUP BY para agregaciones
- Filtrado de datos
- Ordenamiento por métricas clave

## Resultados
- Identificación de productos más rentables
- Detección de tendencias de ventas
